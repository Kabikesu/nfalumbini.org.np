# 🌳 Forest Association Nepal Lumbini Website

A modern, responsive, and GitHub Pages–ready website developed as a practice project for a Forest Association. The website is built using only HTML, CSS, JavaScript, and Bootstrap 5, making it easy to maintain and deploy without a backend.

---

## 📌 Project Overview

This project demonstrates how to build a professional organization website using static web technologies.

The website includes:

- Responsive Home Page
- About Organization
- News & Announcements
- Photo Gallery
- Downloads Center
- Contact Page
- Modern Responsive Design
- Bootstrap 5 Framework
- Font Awesome Icons
- Smooth Scrolling
- Animated Counters
- Back-to-Top Button

# 🌐 Deployment

## Publish using GitHub Pages

1. Create a new GitHub repository.
2. Upload all project files.
3. Commit the changes.
4. Open **Settings**.
5. Select **Pages**.
6. Choose:

```
Deploy from a branch
```

7. Select:

```
Branch: main
Folder: /root
```

8. Save.

Your website will be available at:

```
https://Kabikesu.github.io/forest-association-website/
```

# 📂 Updating Content

## Change Images

Replace files inside:

```
images/
```

Keep the same filenames or update the HTML references.

---

## Add News

Open:

```
news.html
```

Duplicate a news card and update:

- Title
- Date
- Image
- Description

---

## Add Gallery Images

Copy images into:

```
images/gallery/
```

Update:

```
gallery.html
```

---

## Add Documents

Place PDF files inside:

```
documents/
```

Update:

```
downloads.html
```
